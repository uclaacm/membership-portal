# membership-portal

The ACM at UCLA membership portal.

| Directory | What it is |
|-----------|------------|
| [`frontend/`](frontend) | Next.js UI (formerly `uclaacm/membership-portal-ui`) |
| [`backend/`](backend) | Express API |
| [`deployment/`](deployment) | Docker Compose stacks for dev, staging and prod (formerly `uclaacm/membership-portal-deployment`) |

To run everything locally, see [`deployment/README.md`](deployment/README.md).

`frontend/` was merged in with its full history, so `git log` and `git blame` work as before. `deployment/` was imported as a snapshot; its earlier history stays in the archived private repo.
